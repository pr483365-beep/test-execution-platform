# Test Execution & Automation Management Platform

A microservices-based application designed to manage
software testing activities, test cases, and execution results.

## Technology Stack

- Java 17
- Spring Boot
- Spring Data JPA
- MySQL
- Spring Cloud OpenFeign
- Apache Kafka
- Maven
- Git and GitHub

## Microservices

1. Project Service – Manages projects, test suites, and test cases.
2. Execution Service – Manages test execution and results.
3. Reporting Service – Handles execution reports and notifications.

Currently under development.
